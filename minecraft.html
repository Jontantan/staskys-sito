IP Java Edition
minecraft.staskys.it

Al momento è supportata solo la Java Edition. Bedrock non è ancora supportata: niente telefono, console o Bedrock su PC.

Come entrare
  1. Apri Minecraft Java Edition e vai su Multigiocatore.
  2. Clicca Aggiungi server e incolla minecraft.staskys.it.
  3. Entra e crea o unisciti a una fazione.
  4. Sul Discord, scegli il ruolo Minecraft in Canali & Ruoli per vedere info, annunci, changelog e reclutamento.
